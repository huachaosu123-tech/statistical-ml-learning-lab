# Day 1：线性回归与训练／测试集划分

## 1. 学习目标
- 理解特征 X、目标 y 和预测值。
- 理解训练集、测试集与泛化能力。
- 完成一个线性回归实验。

## 2. 核心概念
线性回归通过拟合输入与目标之间的线性关系进行预测。
训练集用于学习模型参数；测试集用于评价模型对未见数据的预测能力。

## 3. 实验计划
- 数据集：scikit-learn Diabetes。
- 划分：80% 训练集，20% 测试集，random_state=42。
- 模型：LinearRegression。
- 指标：MSE、RMSE、R²。
- 笔记本：linear_regression.ipynb。
